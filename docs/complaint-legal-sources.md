The current Civil Code edition began **2026-09-27**. Amendment XV-576 changed information provisions (6.228¹, 6.228⁶–⁸, 6.228¹⁴), while the checked withdrawal and remedy articles remain in the consolidated text. Right-to-repair amendment XV-779 took effect on **2026-07-31** for the checked provisions; its new Civil Code 6.364¹(3) renumbered the secondary remedy condition to **6.364¹(5)**. The older VVTAT page and Retail Rules 20.2 still refer to 6.364¹(4). The current consolidated Civil Code controls, so the letter does not cite that outdated subsection. The existing engine's transitional and special review paths remain conservative; this sprint does not expand right-to-repair claims.

The [VVTAT request page](https://vvtat.lrv.lt/lt/kaip-pateikti-prasyma/) was updated 2026-09-29. The 14-day written response condition applies when a seller disagrees with a consumer demand and is measured from receipt of the request. It is not a universal repair deadline and is not added to a withdrawal notice. Physical-store rules and distance withdrawal have separate clocks and exceptions. Saved versions identify the source/template release used at generation; later legal changes do not rewrite them.

The templates omit unverified merchant contacts, legal conclusions for private sellers or business buyers, extension claims based only on a possible exception, compensation, and any representation that a generated file was sent.
