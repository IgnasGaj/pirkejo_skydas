Calculator `LT-VTA-21-CK-1.118-1.121-2026-10-04.1` applies only to existing `DEFECTIVE_PRODUCT` seller complaints with an explicitly recorded receipt date. These complaints are written claims of consumer-right infringement. Distance withdrawal notices and physical return/consent requests are excluded from this calculator because they have distinct legal bases and the current workflow cannot establish that Article 21 governs each one. The app displays an unavailable reason for them and for unknown receipt dates.

Calculation uses Europe/Vilnius civil dates: exclude receipt date, add fourteen calendar days, then advance only the last day through Lithuanian weekends and public holidays. Public holidays follow the current Lithuanian Labour Code calendar, including Easter Sunday/Monday. The result is an operational reminder based on the user's dates, not an eligibility or jurisdiction decision. Recording an interim reply, follow-up, service handover, or reopening does not restart the original clock. Current receipt and the versioned rule/source identity are saved; a later rule change must be reviewed explicitly rather than silently applying a new computation to an old basis.

The verified Labour Code edition ends on 2026-10-31. The UI therefore withholds a computed date when the current or final day is after that date, until the source set and calculation version are reviewed again. The journal remains usable. This is intentionally narrower than assuming that a later edition is identical.
